# Wiring Learnloop into an agent team

Add to your orchestrator / lead agent's instructions:

```
Before routing a task: read learnloop/memory/lessons.md and, for a repeatable job,
learnloop/memory/playbooks/<job>.md. Pass only the lessons that apply into each
specialist's brief.

Specialists never write to learnloop/memory. They report any human correction or
reviewer comment to you; you record it per learnloop/SKILL.md.

After the job: update its playbook and show the user the one-line notices.
```
