# Reflection

Reflect after a correction, a returned finding, repeated manual work, a wrong route, or a
task that took far longer than its shape suggested. Not after every task.

Reflection never changes anything by itself. It produces an observation; a recurring
observation becomes a lesson or a recommendation.

## Questions, in order

1. What happened?
2. What was correct?
3. What was wrong?
4. **Why**, which cause?

| Cause | Looks like |
|---|---|
| missing knowledge | did not know a rule that exists |
| poor retrieval | the knowledge existed and was not loaded |
| bad routing | wrong specialist, or none |
| weak instruction | did what it was told; the telling was wrong |
| missing capability | no tool could answer |
| incorrect reasoning | everything was available; the conclusion was still wrong |
| missing verification | nobody checked the claim |
| inefficient workflow | right answer, too many steps |
| human ambiguity | the request could be read two ways |

5. Could it happen again?
6. Does it generalise beyond this task?

Question 4 is the one that matters.
